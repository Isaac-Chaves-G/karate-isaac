# TC04: Sirviendo - Terminar Llenado - En Espera

Requisito: @REQ-BAR-04.

Archivo: `src/test/resources/features/barista.feature`.

## Precondiciones y resultado esperado

Barista se reinicia y alcanza su estado inicial mediante `barista-state.feature`; no depende del caso anterior. Climatización recibe tres booleanos: temperatura alta, presencia y apertura prolongada.

```gherkin
Scenario: Sirviendo - Terminar Llenado - En Espera
* def setup = call read('classpath:helpers/barista-state.feature') { estado: 'Sirviendo' }
    Given path 'barista-bot', 'evento'
    And request { evento: 'Terminar Llenado' }
    When method post
    Then status 200
    And match response contains { estadoAnterior: 'Sirviendo', evento: 'Terminar Llenado', estadoNuevo: 'En Espera', valida: true, accion: null }
    Given path 'barista-bot', 'estado'
    When method get
    Then status 200
    And match response.estadoActual == 'En Espera'
```
