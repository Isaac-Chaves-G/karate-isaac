# TC01: En Espera - Iniciar Pedido - Moliendo

Requisito: @REQ-BAR-01.

Archivo: `src/test/resources/features/barista.feature`.

## Precondiciones y resultado esperado

Barista se reinicia y alcanza su estado inicial mediante `barista-state.feature`; no depende del caso anterior. Climatización recibe tres booleanos: temperatura alta, presencia y apertura prolongada.

```gherkin
Scenario: En Espera - Iniciar Pedido - Moliendo
* def setup = call read('classpath:helpers/barista-state.feature') { estado: 'En Espera' }
    Given path 'barista-bot', 'evento'
    And request { evento: 'Iniciar Pedido' }
    When method post
    Then status 200
    And match response contains { estadoAnterior: 'En Espera', evento: 'Iniciar Pedido', estadoNuevo: 'Moliendo', valida: true, accion: null }
    Given path 'barista-bot', 'estado'
    When method get
    Then status 200
    And match response.estadoActual == 'Moliendo'
```

## Ejecución

Añade la etiqueta **ejecutar-prueba** a este issue, o abre Actions → Karate API → Run workflow y escribe `@TC01`. Para repetir desde el issue, quita la etiqueta y vuelve a añadirla.

Local: `./gradlew clean test '-Dkarate.options=--tags @TC01'`.

El workflow publica el resultado y el enlace a la corrida en este issue, y actualiza `automated-passed` o `automated-failed`. Descarga `karate-reports-N` en Artifacts y abre `karate-summary.html`. Un fallo no demuestra por sí solo un bug: revisa la respuesta y las precondiciones.
