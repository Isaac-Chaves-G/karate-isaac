# TC05: Moliendo - Sin Ingredientes - Error de Insumos

Requisito: @REQ-BAR-05.

Archivo: `src/test/resources/features/barista.feature`.

## Precondiciones y resultado esperado

Barista se reinicia y alcanza su estado inicial mediante `barista-state.feature`; no depende del caso anterior. Climatización recibe tres booleanos: temperatura alta, presencia y apertura prolongada.

```gherkin
Scenario: Moliendo - Sin Ingredientes - Error de Insumos
* def setup = call read('classpath:helpers/barista-state.feature') { estado: 'Moliendo' }
    Given path 'barista-bot', 'evento'
    And request { evento: 'Sin Ingredientes' }
    When method post
    Then status 200
    And match response contains { estadoAnterior: 'Moliendo', evento: 'Sin Ingredientes', estadoNuevo: 'Error de Insumos', valida: true, accion: 'Interrumpir flujo' }
    Given path 'barista-bot', 'estado'
    When method get
    Then status 200
    And match response.estadoActual == 'Error de Insumos'
```
