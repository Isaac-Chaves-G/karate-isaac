# TC03: Calentando Agua - Alcanzar Temperatura - Sirviendo

Requisito: @REQ-BAR-03.

Archivo: `src/test/resources/features/barista.feature`.

## Precondiciones y resultado esperado

Barista se reinicia y alcanza su estado inicial mediante `barista-state.feature`; no depende del caso anterior. Climatización recibe tres booleanos: temperatura alta, presencia y apertura prolongada.

```gherkin
Scenario: Calentando Agua - Alcanzar Temperatura - Sirviendo
* def setup = call read('classpath:helpers/barista-state.feature') { estado: 'Calentando Agua' }
    Given path 'barista-bot', 'evento'
    And request { evento: 'Alcanzar Temperatura' }
    When method post
    Then status 200
    And match response contains { estadoAnterior: 'Calentando Agua', evento: 'Alcanzar Temperatura', estadoNuevo: 'Sirviendo', valida: true, accion: null }
    Given path 'barista-bot', 'estado'
    When method get
    Then status 200
    And match response.estadoActual == 'Sirviendo'
```
